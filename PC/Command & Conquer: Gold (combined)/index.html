About

The combined entry contains content from games:

  • Command & Conquer: Tiberian Dawn
  • Command & Conquer: The Covert Operations except bonus CD-Audio tracks

This is a real-time strategy game. It tells a story of world war between GDI (the good guys) and NOD (the bad guys) in alternate history.

The expansion pack contains several new missions for both sides.

Gold version is a re-release for Windows 95 with the game content unchanged.

Music

The music is composed by:

  • Frank Klepacki

And the new expansion tracks also by:

  • Rod Arnett
  • Dan Ryan
  • Greg Greer

Music is the same for both sides.

The game features a jukebox, allowing to select track during gameplay.

The music is stored in AUD proprietary format. It has quality of 22kHz 16bit mono and uses ADPCM compression.

Graphics

The game uses resolution of 640x400 pixels with 256 colors.

The game is based on original DOS latest version: 1.22
