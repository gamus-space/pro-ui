About

This is a sequel of a 3D shooting game. Instead of split-screen play it supports various kinds of network connections.

The available vehicles are:

  • ASV
  • Tank
  • Helicopter
  • Jeep
  • Jet (new)
  • PT Boat (new)

Music

The game has CD Audio tracks.

Game offers classical music set. Music from the first part is reused here, and the new vehicles got new themes.

Graphics

The game supports full 3D rendering engines. Featured version uses 3DFX with resolution of 640x480 with 65k colors.
